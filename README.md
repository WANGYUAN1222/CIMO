# CIMO
The source articles analysed in this study are copyrighted journal publications and cannot be redistributed; a list of their DOIs is provided in the repository. All materials generated by this study are available to editors and reviewers during peer review through an anonymized repository , and will be deposited in a public archive with a permanent DOI upon acceptance: the two-stage extraction prompts and JSON output schemas; the LLM-as-a-judge rubric, weighting scheme, and adjudication prompts used in Stages 1–3; the CIMO-SGD implementation including all pre-specified threshold values, together with the parallel TEXT-RAG baseline; the evaluation scripts that reproduce all reported metrics; the CIMO-SGD (n = 230) and TEXT-RAG (n = 240) candidate-gap portfolios with de-identified human and LLM evaluation scores; and the LoRA adapter configurations for the open-weight student extractors. Code is released under Apache-2.0 and derived data under CC BY 4.0.
